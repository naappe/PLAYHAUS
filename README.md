# PLAYHAUS

PLAYHAUS toy-store storefront and self-service admin console.

- `index.html` — customer store
- `admin.html` — manage products, categories, stock, images, orders and homepage settings
- Supabase — live database, authentication and product-image storage

## Admin
Open `https://naappe.github.io/PLAYHAUS/admin.html`, create/sign in to your account, and use **Claim This Store** for the first admin account.

## Publishing
GitHub Pages should use the `main` branch and `/ (root)` as the source.
